# FF_050 Beta.6 — Bundled Original Music Library

Includes 50 original algorithmically composed instrumental tracks in 5 genres, with full-length (~120 seconds) and loop (~40 seconds) OGG versions (100 files). These are simple synthesized instrumentals, **not commercial songs or professional studio recordings**. All music is original to this package and can be used in exported gaming videos.

Music Library loads automatically from the `music_library` directory. Choose a title and `full` or `loop`, or use `dark survival track 4 loop`. No silent substitutions for unknown titles.

**GitHub Actions / PyInstaller:** The build must include `music_library` as bundled data, e.g. `--add-data "music_library;music_library"` on Windows. Source folder should include music_library.

Full tracks are extended arrangements of the looping synthesized motifs, rather than unique 2–3-minute live performances. The loop versions use short fades, and are not sample-perfect seamless loops. This limitation should be improved in a later audio-production update.
