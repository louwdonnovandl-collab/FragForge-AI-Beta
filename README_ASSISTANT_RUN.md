# FragForge v0.10.25 — Run Edit and Back navigation

1. Enter editing request and select Preview Instructions.
2. Select Run Edit to open the Auto Edit dialog and automatically begin analyzing the video.
3. Review detected segments and enable Replace current timeline to explicitly authorize replacement.
4. Select Apply selected edit to make the actual timeline changes.
5. Back to Assistant returns to the saved request, allowing changes before any edit is applied.

The AI still does not automatically recognize kills or generate captions/visual effects in long-form mode. The Run Edit button starts analysis; it does not bypass user review or consent to replace the timeline.
