# FragForge v0.10.37 — Precision Director

- Parses `60 second short`, `1,5x`, kill focus, music and visual effects deterministically.
- Sets a 60-second output target (not 60 minutes), chooses activity candidate footage at 1.5x.
- Short montage mode now honors duration and speed rather than fixed highlight count.
- User can choose a local music file in Director Edit Preview; music loops/trims on A2.
- Does NOT identify actual kills. Review action candidates.
- Music is not automatically sourced or downloaded; you must choose a file.
- Replace timeline remains opt-in. Preview and export must be tested on Windows.
