# FragForge AI v0.7.0

- Updated the in-app version label to 0.7.0.
- Drag and drop clips in the media/edit list to reorder the timeline.
- Added shortcuts: Space play/pause, Ctrl+K split, Ctrl+Z undo, Ctrl+O open, Ctrl+S save, Ctrl+I import, Ctrl+E export, Delete remove.
- Prevented starting another export while a render is running.
- Retained FFmpeg crossfade rendering from v0.6.

Note: Windows runtime and rendering require local testing.
