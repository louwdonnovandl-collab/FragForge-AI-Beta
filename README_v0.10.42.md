# v0.10.42 — Collapsible Director Edit Preview

The Director Edit Preview now groups settings under five expandable headings: Edit length & playback, Music & sound, Combat detection & review, Highlights & visual effects, and Apply & review.

The scrollable panel keeps Analyze, Cancel, Back and Apply buttons pinned to the bottom. All underlying analysis and editing logic is retained from v0.10.41.

This is a UI-only update. It does not improve automatic combat detection accuracy.
