# FragForge v0.10.24 — AI Assistant foundation

The AI Tools button opens a natural-language editing request box with a deterministic offline interpreter. Preview Instructions generates a transparent plan. Open Auto Edit transfers supported mode, speed-up, sound and effects preferences to the existing analysis workflow. Timeline replacement remains opt-in.

**Important limitations:** The interpreter does not yet understand arbitrary language or perform semantic gameplay recognition. Captions and 20-second intros can be requested and appear in the plan but **are not generated in this version**. Long-form visual effects remain disabled to avoid random overlays. Requested speeds above 2× are disclosed as unsupported. This is an incremental foundation, not the full promised intelligent creative editor.

Validate in Windows GUI and test a project copy before applying edits.
